## 📥 Quick Download & Setup

1. **Download**: Click the **Download Windows (Zip)** badge above or grab the latest zip file from the [Releases Page](https://github.com/ManhLD-LDM/Anime-Expeditions-Aegis-Macro-Releases/releases/latest).
2. **Extract**: Extract the entire `.zip` file into a regular folder on your computer (e.g. `C:\Games\AegisMacro\`).
   > ⚠️ **Do not run `Aegis.exe` directly from inside the compressed zip.** Make sure to extract all files first!
3. **Launch**: Double-click **`Aegis.exe`** to start Aegis Macro.
4. **Auto-Updates**: The app will automatically notify and update itself whenever a newer release is published.

## 🚀 Key Features

- **Tactical Board & Canvas Studio**: Real-time Roblox window capture, zoom & pan focal controls, interactive drag-and-drop macro pins, and right-click action placement.
- **Vanguard Studio HUD**: Sleek, modern dark tactical UI with segmented workspace navigation (Dashboard, Task Planner, Macro Studio, Settings).
- **Macro Sequence Loop Blocks**: Nest actions inside loop containers with custom cycles or infinite repeat (`0 = Infinite`).
- **Full Game Mode Support**: Automated Story stages (1 to 5, Infinite, Mastery), Raids (Act 1, 2, 3), and Expeditions (Difficulty 1, 2, 3).
- **Smart Vision AI**: Fast template matching with automated disconnect detection and recovery.

## ⚙️ Requirements & In-Game Settings

To ensure optimal computer vision detection:
- **Display Resolution**: 1920x1080 recommended (Windows Display Scaling at 100%).
- **Roblox Settings**:
  - Fullscreen or standard windowed mode.
  - Camera Mode: Classic / Follow.
  - Graphics Quality: 1-3 recommended for stable framerates.

## 🛡️ Antivirus Notice (False Positives)

Because `Aegis.exe` is packaged with PyInstaller and automates keyboard/mouse inputs for Roblox, some antivirus software (such as Windows Defender) may flag it as an unrecognized application. 
- You can safely add an exception / exclusion for the extracted folder in Windows Defender.
- All release assets are built in transparent GitHub Actions cloud environments.
